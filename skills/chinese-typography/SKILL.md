# 中文排版规范（Web / 监控大屏）

## 0. 来源标记

- `[clreq §x]`：W3C《中文排版需求》（Requirements for Chinese Text Layout），https://www.w3.org/TR/clreq/
- `[ccg 规则名]`：sparanoid/chinese-copywriting-guidelines《中文文案排版指北》，https://github.com/sparanoid/chinese-copywriting-guidelines
- `[项目约定]`：无外部规范可引用，由本项目确定，写明理由；不得当作行业标准引用
- `[MDN]`：MDN CSS 文档

规则冲突时优先级：`clreq` > `ccg` > `[项目约定]`。`ccg` 是社区惯例，不是标准。

## 1. 中西混排间距

**R1｜汉字与拉丁字母、阿拉伯数字之间留出间隙。**
`[clreq §6.2.2.3]` 行内中西间距最小可挤至 1/8 汉字宽；`[clreq §2.1.3]` 直排给出 1/4 汉字宽的上限；`[clreq §6.2.2.3 注]` 部分排版风格固定为 1/4 汉字宽且不允许挤压。
`[ccg 中英文之间需要增加空格]`、`[ccg 中文与数字之间需要增加空格]` 要求显式加一个空格。
实现：文本内容直接写普通空格（U+0020）或细空格（U+2009）；不要依赖 `text-autospace`（浏览器支持不完整）。UI 组件内可用 `margin-inline: 0.125em` 模拟。

**R2｜全角标点与其他字符之间不加空格。**
`[ccg 全形标点与其他字符之间不加空格]`

**R3｜数字与单位之间加空格，`%`、`‰`、`°`、`℃` 例外。**
`[ccg 数字与单位之间需要增加空格]`；`[clreq §6.1.2.2]` 将百分号、千分号、度数符号与其前数字视为不可拆分整体。
例：`12.5 mg/L`、`35 %` 按 ccg 可写空格，但项目统一写 `35%` 以免断行歧义 `[项目约定]`。

## 2. 标点

**R4｜中文正文使用全角中文标点。**
`[ccg 使用全形中文标点]`；`[clreq §5]`（GB/T 15834—2011 为大陆标点依据）。
完整的英文句子、专有名词、代码内部保持半角 `[ccg 遇到完整的英文整句、特殊名词，其内容使用半形标点]`。

**R5｜引号统一用弯引号 `“”`、`‘’`；不使用 ASCII `"`。**
`[clreq §5.2]` 横排使用弯引号，直排使用直角引号。
`[ccg 简体中文使用直角引号]` 是社区风格建议，与大陆国标不一致；本项目不采用，仅记录备查 `[项目约定]`。

**R6｜书名号用 `《》`（作品名），不用 `<>` 或引号替代。**
`[clreq §5 标点符号]`；`[项目约定]` 产品名、模块名不加书名号。

**R7｜省略号写 `……`（两个 U+2026，共 2em）；破折号写 `——`（2em）。**
`[clreq §5.4.1]` 省略号占两个汉字空间、六个省略点；`[clreq §5.1]` 破折号推荐占两个汉字宽。

**R8｜行首行尾禁则按 basic 级执行。**
`[clreq §6.1.1]` 点号（顿号、逗号、句号、冒号、分号、叹号、问号）、后引号、后括号、书名号后半、连接号、间隔号、分隔号不得出现在行首；前引号、前括号、书名号前半不得出现在行尾。
CSS 映射：`line-break: strict`（仅对中文生效）；不要用 `word-break: break-all`。

**R9｜行末标点压到半字宽，行内点号最小半字宽。**
`[clreq §6.2.2.3]` 行末标点固定半个汉字宽；行内逗号、顿号、分号最小半个汉字宽；连续三个标点可局部放弃禁则作为救济，不作为常规。
Web 无可靠 CSS 实现，属渲染引擎行为 `[项目约定]`：不手写负 margin 去模拟，交给浏览器。

## 3. 断行与换行

**R10｜中文按字断行，不按词断行。**
`[clreq §4.2.2]` 中文词间无空格，词边界需分词计算；因此行内断行发生在汉字之间。CSS 保持 `word-break: normal`、`overflow-wrap: normal`。

**R11｜数字整体不可拆；`%`、`‰`、`°`、`℃` 与前面的数字不可拆；`+`、`-`、`±` 与后面的数字不可拆。**
`[clreq §6.1.2.2]`
实现：给数值加 `white-space: nowrap`；单位与数值放进同一个 inline 容器。

**R12｜2em 标点（破折号、省略号）不可拆到两行。**
`[clreq §6.1.2.1]`

**R13｜英文长词只在必要时断。**
`[项目约定]` 普通英文单词 `overflow-wrap: normal`；URL、哈希、设备编号才用 `overflow-wrap: anywhere`；不要对中文段落开 `hyphens: auto`。

## 4. 字号与字重

**R14｜中文字重只用 400 / 500 / 600 / 700 四档。**
`[项目约定]` 理由：系统中文字体可用字重有限（微软雅黑 3 档、思源黑体多档但需加载、宋体基本只有常规与伪粗）；300 以下在 14px 以下发虚。

**R15｜层级靠字号 + 颜色 + 间距，不靠加粗硬撑；同屏字重不超过 2 档。**
`[项目约定]` 禁止 `font-synthesis: weight` 产生伪粗。

**R16｜最小字号：Web 正文 ≥14px，辅助信息 ≥12px 且仅限非关键，表格与标签 ≥13px。**
`[项目约定]` 12px 以下中文在 1x 屏不可读。

**R17｜大屏（1920×1080，观看距离 3m）字号下限：正文 ≥18px，标签 ≥16px，关键数值 ≥32px，页面标题 ≥28px；全屏不出现 <14px 中文。**
`[项目约定]` 依据：3m 距离下 14px 汉字的视角过小；1920 宽的 1px 线在远距不可辨，因此字号与线宽需同时放大。

**R18｜行高：中文正文 1.6–1.8，标题 1.2–1.35，大屏单行标签 1.2–1.3。**
`[项目约定]`；`[clreq §6.4]` 给出中文行距常见范围为字号的 50%–100%。

## 5. 数字与字面率

**R19｜所有会变化的数值使用等宽数字。**
`[MDN font-variant-numeric]` `font-variant-numeric: tabular-nums;`
中文字体默认数字常为比例字形，必须显式开启，否则实时刷新会左右跳动。

**R20｜数字使用半角字符。**
`[ccg 数字使用半形字符]`

**R21｜中文语境用 `万` / `亿`，不用 `K` / `M`；同一屏单位体系统一。**
`[项目约定]`

**R22｜数值与单位、数值与状态之间用固定间距，不靠空格对齐。**
`[项目约定]` 用 grid 列宽或 `ch` 单位，不用多个 `&nbsp;`。

## 6. 字体与字面

**R23｜中文 fallback 顺序固定，避免不同机器字面率跳变。**
`[项目约定]`
```
font-family: "Noto Sans SC", "Source Han Sans SC", "Microsoft YaHei", "PingFang SC", sans-serif;
```
不要把衬线体用于 14px 以下正文。

**R24｜中英混排的行高取中文字体需求，不取拉丁字体的紧凑值。**
`[项目约定]` 拉丁字体 1.2 行高会让中文上下贴边。

**R25｜中文短标签不要两端对齐。**
`[项目约定]`；`[clreq §6.2]` 的两端对齐针对书籍正文，不适用于 UI 控件。UI 默认 `text-align: left`。

## 7. 可执行检查清单

代码层（可 grep / lint）：

- [ ] 正文出现 `word-break: break-all` → 禁止
- [ ] 中文段落出现 `hyphens: auto` → 禁止
- [ ] 动态数值缺少 `tabular-nums` → 补
- [ ] 中文字体栈缺少 `Microsoft YaHei` / `PingFang SC` → 补
- [ ] 文本中 CJK 与 `[A-Za-z0-9]` 紧贴且无空格 → 补空格（URL、代码、型号除外）
- [ ] 出现 `。。`、`，，`、`！！`、`??` 等重复标点 → 修正
- [ ] 中文正文里出现 ASCII 直引号 `"` → 改为 `“”`
- [ ] 中文里出现 `<...>` 当书名号 → 改为 `《》`
- [ ] 中文正文 `< 14px`，大屏 `< 16px` → 修正
- [ ] 同屏字重超过 2 档 → 收敛

视觉层：

- [ ] 行首是否出现 `，。、；：？！）》」`
- [ ] 行尾是否出现 `（《「`
- [ ] 数字刷新时是否横向抖动
- [ ] 单位是否与数值分离到两行
- [ ] 省略号是否为 6 点、破折号是否为 2em
